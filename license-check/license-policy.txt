# Licenses approved for plaid's dependencies. Ported from liccheck.ini
# (sc-24172). Matching is case-insensitive; see scripts/check_licenses.py.
#
# Two forms are listed on purpose. Trivy normalises many packages to an SPDX
# identifier, but passes a package's declared text through verbatim when it
# cannot — so `Apache-2.0` and `Apache Software License` both reach the policy
# and both have to be named. That is the same reason liccheck.ini carried ~60
# spellings of a dozen licenses; this is a port of that list, not a rewrite.
#
# Compound SPDX expressions (`MPL-2.0 AND (Apache-2.0 OR MIT)`) need no entry:
# they are split into atoms and each atom is checked. Only free-text names need
# to be spelled out.
#
# NEVER add a compound-looking `X AND/OR/WITH Y` line here unless you mean to
# approve exactly that verbatim joint string. Because a whole string is matched
# before it is split, such a line does not approve X and Y separately — it
# creates a narrow allowance for that one spelling, and would carry a
# disallowed half in with it. `lgpl with exceptions or zpl` below only looks
# like one; it is a single license name inherited from liccheck.ini.

#   license liccheck could not determine. That is the whole of the cautious
